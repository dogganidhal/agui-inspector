---
title: Embed in Starlette or FastAPI
description: Serve the inspector from your own Starlette or FastAPI application with one helper call.
---

Python is the first server language with an embedded helper, and it will not be the only one: JavaScript helpers for Express, Hono and Next.js are planned for 1.0.0. A server in any other language can already use the [hosted page](./hosted.mdx) or [serve the static assets](#serving-the-assets-from-another-server).

The Python package `agui-inspector` (MIT) contains the prebuilt inspector files and one helper, `mount_inspector`, that serves them from your Starlette or FastAPI application. The host needs no Node toolchain, and the helper downloads nothing at startup. Version 0.1.0 is on [PyPI](https://pypi.org/project/agui-inspector/).

The helper adds a separate page to your server. That page sends its own requests to your agent URLs, so it records the runs it starts. It does not attach to the agent that your own frontend runs, and it does not see that agent's requests. Watching your application's `AbstractAgent` is the planned in-app mode (see the [roadmap](https://github.com/dogganidhal/agui-inspector/blob/main/ROADMAP.md#100-stable-target)). It is not built yet.

## Quick start

<Steps>
<Step>

Install the package from PyPI with the `embedded` extra, which adds Starlette. Use pip in a virtual environment, or uv in a uv project:

```sh tab="pip" tab-group="python-installer"
pip install "agui-inspector[embedded]"
```

```sh tab="uv" tab-group="python-installer"
uv add "agui-inspector[embedded]"
```

</Step>
<Step>

Mount the inspector behind a setting that is off in production. Add this after you create your application. Replace `app` with your application object and `settings.debug` with your development-only setting.

```python
from agui_inspector import Agent, mount_inspector

mount_inspector(
    app,
    agents=[Agent(id="support", url="/agents/support/stream")],
    enabled=settings.debug,
)
```

</Step>
<Step>

Start the application and open `/agui-inspector`, for example `http://127.0.0.1:8000/agui-inspector`. The page lists the `support` agent and calls its URL directly.

</Step>
<Step>

Type `Hello` in the message box and send it. Your agent's reply appears in the conversation. The Inspection tab shows the request as one exchange, with every frame the agent streamed back.

</Step>
</Steps>

FastAPI uses the same call because it is a Starlette application. The package itself depends on no framework, so a host that never enables the inspector installs nothing extra.

## Arguments

| Argument | Meaning |
| --- | --- |
| `agents` | The agents the page lists. `Agent` needs `id` and `url`. `name`, `capabilities` and `preset` are optional and mean the same as in the [configuration file](./configuration.mdx#configuration-file). Ids must be unique. |
| `enabled` | Default `False`. A disabled call returns before it imports Starlette, registers a route or logs anything. |
| `path` | The page's path, default `/agui-inspector`. It must start with `/` and cannot be `/` alone. A trailing `/` is ignored. |
| `theme` | Optional `{"light": {...}, "dark": {...}}`. Each map is optional and maps the ten public `--agui-*` names to CSS values, for example `{"light": {"--agui-accent": "#2563eb"}}`. The helper writes it into `config.json` as given. |

## Debug guard

<Callout type="warn">
The inspector shows request bodies, raw frames and your agent list to anyone who can reach the route. Tie `enabled` to something that is off in production, such as `settings.debug`.
</Callout>

When enabled, the helper logs one warning through the `agui_inspector` logger, for example `agui-inspector is enabled and mounted at /agui-inspector; disable it outside development`. If that warning appears in a production log, the guard is wrong.

## Theming the embedded page

The helper does not check `theme`. The page checks it when it loads `config.json`, applies the map for the current light or dark mode, and shows a "Configuration" warning for each name or value it rejects. A rejected entry never stops the page or the agents from loading. A misspelled property name gives a warning and no visible change. The rules are in [configuration](./configuration.mdx#theme) and the properties in [theming](./theming.mdx#public-properties).

`theme` changes nothing else: same routes, same content security policy header, no extra request. A host that serves the assets itself puts the same `theme` field in its own `config.json`.

## Routes

With the default path the helper adds:

| Route | Response |
| --- | --- |
| `GET /agui-inspector` | A 307 redirect to `/agui-inspector/` that keeps the query string, so the page's relative script URL resolves. The `Location` includes the ASGI (Asynchronous Server Gateway Interface) `root_path`, which holds the prefix of every outer mount. Under `outer.mount("/api", app)` it is `/api/agui-inspector/`. |
| `GET /agui-inspector/` | The inspector page. |
| `GET /agui-inspector/config.json` | The version-0 configuration built from `agents` and `theme`: `{"version": 0, "agents": [...], "theme": {...}}`. Fields left as `None` are left out, and so is `theme` when you pass none. The page reads it from its own directory, so a custom `path` works the same way. |
| `GET /agui-inspector/<file>` | A packaged asset, including nested ones. Anything else is a 404. |

The helper rejects other methods. It adds no session endpoints, no storage and no proxy for the agent. The page calls your agent URL directly, and a captured session never reaches the server.

Every response carries `Content-Security-Policy: script-src 'self'; object-src 'none'; base-uri 'none'`, the same policy as the page's own `<meta>` element. Scripts load only from the page's origin, and `eval` is blocked. The helper reads assets through `importlib.resources`, rejects `..` segments and backslashes, and serves only files under the packaged `static` directory.

## Authentication

The helper adds no authentication. Whatever guards the rest of your application also guards the inspector. The page calls relative agent URLs on the same origin, so the browser sends the credentials it already has for your site. `Agent` has no field for credentials, so the configuration never contains any.

These guards cover the page, `config.json`, the assets and the slash redirect:

- Middleware on the application you pass to `mount_inspector`, or on any application that mounts it.
- A reverse proxy or gateway in front of the inspector path.
- On FastAPI, the application-level dependencies of the application you pass, as in `FastAPI(dependencies=[Depends(require_login)])`. The helper registers API routes on a FastAPI application, so those dependencies run for all four routes. The routes do not appear in the OpenAPI schema.

<Callout type="warn">
One setup is not covered: a dependency on an application that mounts yours. FastAPI does not run the dependencies of an outer application for a mounted sub-application. With `outer = FastAPI(dependencies=[...])` and `outer.mount("/api", app)`, the inspector in `app` is served and that dependency never runs. Put the dependency on `app` itself, or guard with middleware on `outer` or with the proxy. A plain Starlette application has no dependency system, so it needs middleware or the proxy.
</Callout>

The guard must accept what a browser sends when it opens a page. A plain page load sends cookies and saved HTTP Basic credentials, but it cannot send a custom header. So a guard that accepts only `Authorization: Bearer <token>` blocks the inspector page itself. Typing a token into the page cannot help, because the page never loads. Guard the inspector paths with a session cookie, HTTP Basic or a proxy that adds the credential. Your agent routes behind that guard can still require a bearer token: the page's Authentication control sends one header with each agent request. Keep the header name `Authorization` and type the complete value, `Bearer <token>`, in the Token field. See [the token](./runs.mdx#the-token).

[`examples/fastapi/app.py`](https://github.com/dogganidhal/agui-inspector/blob/main/examples/fastapi/app.py) is a host with no model. Middleware checks HTTP Basic authentication on every route. It reads `EXAMPLE_USER` and `EXAMPLE_PASSWORD` from the environment and mounts the inspector only when `EXAMPLE_DEBUG=1`. It streams one scripted run from `POST /agents/demo/stream`. From the repository root, build the package, then run the example. With pip, a virtual environment holds the package and the example's FastAPI and uvicorn, which the package's `test` dependency group lists (`--group` needs pip 25.1 or newer). With uv, `uv run` uses the locked versions:

```sh tab="pip" tab-group="python-installer"
npm run package:python
python3 -m venv .venv
source .venv/bin/activate
pip install "packages/python/dist/agui_inspector-0.1.0-py3-none-any.whl[embedded]" \
  --group packages/python/pyproject.toml:test
EXAMPLE_USER=dev EXAMPLE_PASSWORD=choose-a-password EXAMPLE_DEBUG=1 \
  python examples/fastapi/app.py --port 8000
```

```sh tab="uv" tab-group="python-installer"
npm run package:python
EXAMPLE_USER=dev EXAMPLE_PASSWORD=choose-a-password EXAMPLE_DEBUG=1 \
  uv run --project packages/python --locked --extra embedded --group test \
  python examples/fastapi/app.py --port 8000
```

Open `http://127.0.0.1:8000/agui-inspector/` and sign in with that user and password when the browser asks. The page lists Demo agent. Send any message, and the agent answers `Hello from the FastAPI example.` If port 8000 is taken, pass another `--port` and change the URL.

## Serving the assets from another server

Any static file server can host the same inspector. The npm package exports `staticAssetsPath` from [`static-path.js`](https://github.com/dogganidhal/agui-inspector/blob/main/packages/inspector/src/static-path.js). Serve the directory it points at, put a `config.json` next to its `index.html`, and open the page. The npm package has no CLI and no server helper. See also [Host the static page](./hosted.mdx).

## Working from a source checkout

Use a checkout to run the example, to try changes that are on `main` but not released yet, or to work on the package. You need git, Node 24 or newer with npm, and [uv](https://docs.astral.sh/uv/): `npm run package:python` builds the wheel with `uv build`. Once the wheel is built, you can install and run it with pip or uv.

```sh
git clone https://github.com/dogganidhal/agui-inspector.git
cd agui-inspector
npm ci --ignore-scripts
npm run package:python
```

The static files are not committed. A fresh checkout has no `src/agui_inspector/static` directory, and `mount_inspector(enabled=True)` raises an error that names `npm run package:python`. That command builds the assets, copies them into the package, writes `static.sha256` and runs `uv build`. It leaves a wheel and a source distribution in `packages/python/dist`. [Releases](./releases.mdx) describes what it checks.

To see the page working, start the example from [Authentication](#authentication). To use the built wheel in your own project instead of the PyPI release, install the file. Its name contains the version:

```sh tab="pip" tab-group="python-installer"
pip install "/path/to/agui-inspector/packages/python/dist/agui_inspector-0.1.0-py3-none-any.whl[embedded]"
```

```sh tab="uv" tab-group="python-installer"
uv add "agui-inspector[embedded] @ /path/to/agui-inspector/packages/python/dist/agui_inspector-0.1.0-py3-none-any.whl"
```
 For the package's test commands, see [Architecture and UI internals](./internals.mdx#python-package-tests).
