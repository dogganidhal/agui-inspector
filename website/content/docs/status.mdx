These docs describe the `main` branch. Every push to `main` also deploys the public demo. The Python package's
[changelog](https://github.com/dogganidhal/agui-inspector/blob/main/packages/python/CHANGELOG.md) lists what each release changed.

## What is implemented

Version 0.1.0 (the minimum viable product) is implemented on `main`. The public demo has been online since
2026-10-02. You can try it in the [demo](./demo.mdx) or from a checkout
([development](./development.mdx)).

| Mode | Status |
| --- | --- |
| Hosted static page with a `hosting-config.json` | Available: the [demo](./demo.mdx) is one, or build the page from a checkout |
| Embedded in Starlette or FastAPI, through `mount_inspector` | 0.1.0 on PyPI: `pip install "agui-inspector[embedded]"` |
| Static assets from the npm package's `staticAssetsPath`, served by any other server | 0.1.0 on npm: `npm install agui-inspector` |
| CLI: `agui-inspector`, a local command that serves the page and proxies to the targets you name | In 0.2.0, not released yet. See [Run it locally with the CLI](./cli.mdx) |
| Embedded in Express, Hono or Next.js, through `agui-inspector/express`, `agui-inspector/hono` and `agui-inspector/next` | In 0.2.0, not released yet. See [Embed in your server](./embedding.mdx#javascript-servers) |
| In-app: a custom element that watches an `AbstractAgent` your application already runs | Not planned. See the [roadmap decisions](https://github.com/dogganidhal/agui-inspector/blob/main/ROADMAP.md#decisions) |

Python has had an embedded helper since 0.1.0. The JavaScript helpers arrive with 0.2.0. A server in any other language
can use the hosted page or serve the static assets.

## Where your data goes

- The page sends no telemetry and loads nothing from third parties. It talks only to its own origin and to the targets
  you configure.
- Your browser sends each run directly to the agent, with no proxy. The one exception is the [CLI](./cli.mdx): its page
  sends the run to a proxy on your own machine, which relays the exact bytes to the target you named and to no other
  host. A hosted page sends no cookies, not even to its own origin. An embedded page calls your agent on the same origin, so the browser adds the credentials it already has for
  your site.
- The page keeps the session (exchanges, frames and findings) in memory. No server stores it, and a reload clears it.
- The page saves the client profile in browser storage under `agui-inspector.profile`. It saves `forwardedProps`,
  `context` and the tool schemas as you typed them, so do not put secrets in them.
- The page saves the theme you pick with the top-bar switch in browser storage under `agui-inspector.theme`. It saves
  only the word `light` or `dark`.
- A recording exists only as a file you exported to your disk.
- The token you type stays in memory, and the page sends it only in the header you choose. The page never writes it to
  browser storage, configuration, a profile, a recording, an export or a log. The recorder reads no headers, and a
  reload clears the token.

<Callout type="warn">
The inspector keeps frames and request bodies exactly as sent and received, so they can contain secrets or
personal data. If a server repeats your token in a payload, the token is in the session and in every export. Check a
recording before you share it: [read this before you share a file](./recordings.mdx#read-this-before-you-share-a-file).
</Callout>

## Embedded routes need your protection

`mount_inspector` adds no authentication. When the embedded inspector is enabled, anyone who can reach its route sees
request bodies, raw frames and your agent list. Put the route behind your application's authentication. Set `enabled`
(default `False`) from a setting that is off outside development. [Embedding](./embedding.mdx) describes the debug guard
and the warning it logs.

## Formats are pre-stable

The configuration (including presets), the client profile and recordings are at version 0 and not stable yet.
Until 1.0.0, a release can change them in incompatible ways without changing the version number. One release may
refuse a recording made by another. [Configuration](./configuration.mdx) lists breaking changes to these files and to
`hosting-config.json`, with their migration steps, and the changelog announces them. Version 1, with published JSON
Schemas, comes only with a stable release, and the roadmap plans none yet. [Recordings](./recordings.mdx) describes the recording format.

## Supported versions

| What | Supported |
| --- | --- |
| AG-UI | Protocol 1.0, the 31-event baseline, over HTTP, as Server-Sent Events (SSE) or [protobuf](./protobuf.mdx), with `@ag-ui/core`, `@ag-ui/client` and `@ag-ui/proto` 1.0.1 ([dependencies](./dependencies.mdx)) |
| A2UI | v0.8 and v0.9, told apart per surface. An entry that is neither is reported with its position and skipped ([A2UI surfaces](./a2ui.mdx#versions)). |
| Python, for the embedded helper | 3.10 or newer. CI runs 3.10 and 3.14. |

## Browser coverage

The end-to-end tests run only in Chromium. For local servers, the tests check how the hosted page handles
`localhost` and `127.0.0.1` in Chromium. The same cases were checked by hand in Safari, and Firefox has not been
checked. These checks cover only these cases, not browser compatibility in general. Treat every other
loopback address or name as unsupported ([browser check](./hosted.mdx#browser-check)).

## Report a bug or a vulnerability

- Report a bug with the [GitHub issue forms](https://github.com/dogganidhal/agui-inspector/issues/new/choose). The form
  asks for what happened, the steps from opening the page, the mode, the commit you built from or the date you used the
  demo, your browser and operating system, and what the server sent. For the demo, the steps include the example agent
  and the quick message. Paste only synthetic or redacted data.
- Report a vulnerability privately, as [SECURITY.md](https://github.com/dogganidhal/agui-inspector/blob/main/SECURITY.md)
  describes. Do not use a public issue. Security reports cover `main` and the public demo.
- To propose a change, read
  [CONTRIBUTING.md](https://github.com/dogganidhal/agui-inspector/blob/main/CONTRIBUTING.md).

To see the inspector before you decide, [try your first run](./demo.mdx).
