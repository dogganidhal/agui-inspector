# Tasks: Client automation

**Input**: [spec](spec.md), [plan](plan.md), [research](research.md), [data model](data-model.md),
[contracts](contracts/automation.md), [validation guide](quickstart.md).

**Format**: `- [ ] Txxx [P?] [USn?] Description with file path`. `[P]` means the task touches different files from the other
open tasks of its phase and can run in parallel with them. `[USn]` maps a task to a user story of the spec. Tests are
required by the constitution and by FR-022, so each story lists its tests before its code.

**One pull request.** The work is small, so there are no slices. Stories are ordered by dependency, and the phases below
say what can run in parallel. Nothing here publishes, tags or releases, and `ROADMAP.md` stays as it is.

**Stories**: US1 interrupts (P1), US2 tool results (P1), US3 marks (P1), US4 profile settings and files (P2), US5 loop
guard (P1).
